¶ Importação de Dados

Com o Syn Privado, é possível realizar a importação de dados utilizando os Layouts de Importação (NLI). Esses NLIs permitem a transferência de informações de maneira eficiente, tanto para entrada quanto para saída de dados, quando estiverem configurados adequadamente à finalidade desejada.

Confira abaixo como realizar os processos:

¶ IMPORTAÇÃO DE DADOS

O Syn Privado permite a importação de dados utilizando Layouts de Importação (NLI).

Requisitos para Importações:

  • Token de Login: Gerado no momento do login.
  • NLI para importação.

Com essas informações, é possível importar as informações desejadas.

Endpoint para Importação: O Endpoint utilizado para a importação de dados é: GET - api/Integracao/Importar.

Parâmetros Necessários:
TokenApi: Token gerado no login.

No Body da requisição você irá informar o nome dos Layouts, o conteúdo que está dentro do arquivo NLI* e o conteúdo do arquivo de dados*.

Observação: Ambos devem estar convertidos em Base64.

¶ Parâmetros Obrigatórios do Body

  • Leiautes: Neste parâmetro serão informados todos os NLIs utilizados para a importação. Dentro dele haverão dois parâmetros:
    • Nome: Nome do NLI
    • Arquivo: O conteúdo que está dentro do arquivo NLI convertido em Base64.
    • Dados: O conteúdo do arquivo de dados convertido em base64
    • PodeAlterarDados: Se informado como True, caso já exista o registro informado no arquivo de dados o sistema irá atualizar o registro. Se informado como False o registro só será importado caso não exista no sistema.
    • ExecutarValidacaoFinal: É uma opção que quando informada como sim realiza validações no conjunto dos dados que estão sendo importados. Quando houver diferenças não importará os dados, desde que o parâmetro Permitir Erros esteja como não.

¶ Exemplo de Requisição: Importação de Sócios

Resposta Esperada

¶ Validação de Respostas

A resposta ao executar um relatório via API deve ser equivalente à obtida ao realizar o mesmo processo manualmente no sistema.

Se a requisição retornar status 200 mas o resultado indicar um erro, revise os dados que estão sendo importados na tag Dados para garantir que estão corretos.
