¶ Consultar Telas do Sistema

O Syn Privado permite consultar informações das telas de cadastro do Questor, como, por exemplo, a tela de cadastro de funcionários. Para realizar essa consulta, são necessários os seguintes dados:

  • Nome Interno da Rotina (_AActionName)
  • Parâmetros da Rotina

Com essas informações, é possível acessar os dados armazenados nas rotinas de cadastro do sistema.

¶ Endpoint para Executar Rotinas

O Endpoint utilizado os dados de cadastro é: GET - /TnWebDMConsulta/Pegar

Parâmetros Necessários
Parâmetro Descrição
_AActionName Nome interno da consulta a ser acessada
_AiDisplayStart Indica qual o primeiro registro que deve ser retornado, valor maior ou igual a 0 (zero).
_AiDisplayLength Indica quantos registros deve retornar a partir do primeiro indicado no parâmetro _AiDisplayStart.
_AOrderBy Indica qual coluna da consulta deve ser utilizada para ordenar os dados.
_AsEcho Indica a ordem dos dados da consulta. Valores Desc e Asc.

Além dos parâmetros mencionados, caso a rotina possua parâmetros obrigatórios, será necessário informar um Body na requisição. Para construir este Body, utilize o retorno do Endpoint GET - api/TnWebDMDadosObjetos/Pegar, apresentado na seção de primeiros passos.

⚠️ Importante: Existe um parâmetro obrigatório chamado "Filter", que não é retornado pelo endpoint de consulta de parâmetros. Ele deve estar presente no Body da requisição, mesmo que não sejam informados filtros específicos.

¶ Exemplo: Consultar cadastro de Empresa

http://localhost:8080/api/TnWebDMConsulta/Pegar?_AActionName=TnGemDCEmpresa&_AsEcho=Desc&_AiDisplayStart=0&_AiDisplayLength=1000&_AOrderBy=1
