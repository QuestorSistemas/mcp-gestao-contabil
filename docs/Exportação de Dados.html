¶ Exportação de Dados

Com o Syn Privado, é possível realizar a exportação de dados utilizando os Layouts de Importação (NLI). Esses NLIs permitem a transferência de informações de maneira eficiente, tanto para entrada quanto para saída de dados, quando estiverem configurados adequadamente à finalidade desejada.

Confira abaixo como realizar os processos:

¶ Exportação de Dados

O Syn Privado permite a importação de dados utilizando Layouts de Importação (NLI).

  • Requisitos para Importações:
    • Token de Login: Gerado no momento do login.
    • NLI para importação.

Com essas informações, é possível importar as informações desejadas.

¶ Endpoint para Exportação

O Endpoint utilizado para a exportação dos dados é: api/Integracao/Exportar.

  • Parâmetros Necessários:
    • TokenApi: Token gerado no login.

No Body da requisição, você irá informar o nome dos Layouts e o conteúdo que está dentro do arquivo NLI .

Observação: Devem estar convertidos em Base64.

¶ Parâmetros Obrigatórios do Body.

Leiautes: Neste parâmetro, serão informados todos os NLIs utilizados para a exportação. Dentro dele haverão dois parâmetros:

  • Nome: Nome do NLI
  • Arquivo: O conteúdo que está dentro do arquivo NLI convertido em Base64.

Filtro: Tag utilizada para filtrar as informações exportadas.

¶ Validação de Respostas

A resposta ao executar um relatório via API deve ser equivalente à obtida ao realizar o mesmo processo manualmente no sistema.

Se a requisição retornar status 200, mas o resultado indicar um erro, revise o NLI Utilizado e o filtro inserido.
